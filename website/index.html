The serial terminal that stays out of your way.

TinySerial is a small, fast desktop tool for talking to microcontrollers, boards and modems over UART. Plug in, pick a baud rate, and read the boot log.

Features

Everything you need at the bench. Nothing you don't.

One window, no project files, no plugins. Open it, pick a port, start reading.

Hot-plug detection

The port list refreshes the moment a USB-serial adapter is plugged in or pulled out. An open port stays open until its device disappears.

ASCII and HEX

Send and receive in either format, chosen separately for each direction. Malformed HEX is rejected before it reaches the wire.

Auto-repeat

Fire the same frame every N milliseconds for polling, soak tests or keeping a watchdog fed.

Timestamps and echo

Stamp every line with the time it arrived and show what you sent inline, so the log reads like a conversation.

Save the session

Export the whole exchange to a log file to attach to a bug report, or pause the view while the data keeps flowing.

Every port setting

Standard or custom baud rates, data bits, parity, stop bits and flow control, with live byte counters for each direction.

Install

Up and running in one paste.

The block picks the right apt suite for your Ubuntu release and adds you to the dialout group.

(
  . /etc/os-release
  case "$VERSION_ID" in
    20.04) suite=focal ;;
    22.04) suite=jammy ;;
    24.04) suite=noble ;;
    26.04) suite=resolute ;;
    *) echo "Ubuntu ${VERSION_ID:-unknown} is not a published TinySerial target." >&2; exit 1 ;;
  esac
  sudo curl -fsSL https://apt.mltz.tech/key.gpg -o /usr/share/keyrings/mltz.gpg
  echo "deb [signed-by=/usr/share/keyrings/mltz.gpg] https://apt.mltz.tech ${suite} main" | sudo tee /etc/apt/sources.list.d/mltz.list
  sudo apt-get update
  sudo apt-get install -y tinyserial
  sudo usermod -a -G dialout "$USER"
)

Prefer not to add an apt repository? Download the .deb for your Ubuntu release from GitHub Releases, for example tinyserial_2.0.0_ubuntu24.04_amd64.deb on 24.04, and install it with apt so the Qt libraries come along.
